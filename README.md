# PixSnap 2.0 📸

原生 macOS 高性能多屏截图、智能窗口吸附、专业标注、置顶贴图（Pin）与本地离线 OCR / 二维码识别工具。  
基于 Swift 6 与 macOS 14+ 原生框架（ScreenCaptureKit、Vision、VisionKit、CoreImage、ServiceManagement、Carbon）构建，零第三方依赖，纯原生编译运行。

---

## 🌟 核心特性

1. **多显示器并发捕获 & GPU 分层零重绘渲染**
   * 单次 `ScreenCaptureKit` 会话并发抓取所有外接/内置显示器，精准匹配 `CGDirectDisplayID` 与 Retina 缩放比。
   * 完整保留屏幕原生广色域（如 Display P3），拒绝导出偏色发灰。
   * 静态底图通过独立 `CALayer` GPU 合成，鼠标移动与绘制标注全程零整屏位图重绘，丝滑跟手。
2. **智能窗口吸附 & 精准零拷贝像素放大镜**
   * 跨屏准确识别应用窗口边界并自动裁切防越界，支持 `⌘A` 一键全屏选区，选区四边与八个控制点均可自由拖拽，支持方向键 1pt / `⇧+方向键` 10pt / `⌥+方向键` 微调尺寸。
   * 15×15 等比正方形像素网格放大镜，O(1) 单像素采样零整屏内存拷贝，贴近屏幕角落时中心准星依旧严丝合缝。
   * **快捷键 `C`** 一键复制当前像素颜色并弹出 Toast 提示，**`Tab`** 循环切换 `HEX (#RRGGBB)` / `HEX无#` / `RGB` / `HSL` 格式。
3. **双层毛玻璃标注工具箱（支持选中编辑与撤销/重做）**
   * 🔲 **矩形 (`1`) / ⭕ 椭圆 (`2`)**：支持描边与半透明填充切换，按住 `Shift` 约束正方形 / 正圆。
   * ➡️ **现代渐宽箭头 (`3`)**：优雅收尾绝不穿模，按住 `Shift` 45° 对齐。
   * ✏️ **平滑画笔 (`4`) / 🖍️ 荧光高亮笔 (`5`)**：二次贝塞尔平滑曲线，荧光笔正片叠底不遮文字，按住 `Shift` 绘制直线高亮。
   * 🟩 **像素马赛克 / 高斯模糊 (`6`)**：按需懒加载生成，支持在马赛克与高斯模糊间一键切换及三档笔刷尺寸。
   * 🔤 **高对比文字标注 (`7`)**：行内输入支持 `↵` 确认、`⇧↵` 换行、实时切换字号/颜色，导出零丢失、零跳位。
   * 🔢 **序号标注 ①②③ (`8`)**：自动递增编号，支持一键重置序号。
   * ✋ **选中与编辑**：未激活画笔时可直接点击已有标注进行拖动、改色、调粗细或按 `Delete` 删除；完整支持 **`⌘Z` 撤销** 与 **`⌘⇧Z` 重做**。
4. **增强置顶贴图（Pin 📌）**
   * 贴图支持 **Apple Live Text 原生直接划选复制文字**（按住 `Option` 强制拖拽窗口），并随选区/标注变化自动同步更新。
   * 支持**快捷键直接贴剪贴板图片或文本卡片**（默认 `⌥ + ⇧ + V`）。
   * **跨桌面空间 & 全屏应用置顶**、浅色截图细边框、滚轮/捏合缩放百分比 HUD（支持左上角/中心/鼠标锚点切换）、中键 / `0` 重置 100%、`H` 折叠缩略图、`R` 旋转 90°、**鼠标穿透模式**（可从菜单栏一键恢复）。
5. **离线 OCR 文字与二维码识别 📝**
   * 支持独立快捷键「快速截图 OCR」（默认 `⌥ + ⇧ + O`），划选松手直出结果并自动复制。
   * 同步识别中英日文与二维码/条形码，识别到链接支持一键打开浏览器，支持「合并换行」整理段落。
6. **现代多标签偏好设置 ⚙️**
   * 支持开机自启动（`SMAppService`）、自定义保存目录与 PNG/JPEG 格式、`⌘S` 快速保存 & `⌘⇧S` 另存为、剪贴板 PNG+TIFF 双格式写入、三组全局快捷键防误录与冲突检测。

## ⌨️ 常用快捷键速查

| 场景 | 快捷键 | 功能 |
| :--- | :--- | :--- |
| 全局 | `⌘ + ⇧ + X` | 区域截图（可在偏好设置修改） |
| 全局 | `⌥ + ⇧ + V` | 贴剪贴板图片 / 文字 |
| 全局 | `⌥ + ⇧ + O` | 快速截图识别文字 OCR |
| 截图悬停 | `C` / `Tab` | 复制当前像素色值 / 切换颜色格式 |
| 截图选区 | `1` ~ `8` | 快速切换 8 种标注工具 |
| 截图选区 | `⌘A` / `⌘Z` / `⌘⇧Z` | 全屏选区 / 撤销 / 重做 |
| 截图选区 | `↵` / `⌘C` / 双击 | 完成并复制到剪贴板 |
| 截图选区 | `T` / `⌘P` | 置顶贴图（Pin） |
| 截图选区 | `⌘S` / `⌘⇧S` | 快速保存到默认目录 / 另存为 |
| 贴图窗口 | `⌘C` / `⇧C` / `⌘⌥C` | 复制划选文字或图 / 复制全文 / 仅复制图 |
| 贴图窗口 | `H` / `R` / `0` / `Esc` | 折叠缩略图 / 旋转 90° / 重置 100% / 关闭 |
